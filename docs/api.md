# REST API Documentation

## Endpoints Summary
- `GET /api/health`: Health status & system mode
- `POST /api/location`: City search & geocoding
- `POST /api/environment/profile`: Climate & soil normalization profile
- `GET /api/materials`: Available building materials
- `POST /api/design/candidates`: Candidate generator
- `POST /api/ml/predict`: ML surrogate thermal prediction
- `POST /api/optimization/run`: Multi-objective design optimizer
- `POST /api/simulation/run`: ANSYS simulation runner
- `POST /api/validation/run`: ML vs ANSYS error validation
- `POST /api/agent/run`: Agentic AI tool orchestrator
- `POST /api/report/generate`: Executive engineering report generator
